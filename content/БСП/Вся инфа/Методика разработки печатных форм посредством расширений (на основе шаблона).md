> [[База знаний БСП]]

##### <span style="color:rgb(0, 176, 80)">1.</span> Загрузить расширение обработку из файла шаблона **`ШаблонОбработкиПечатиНаОсновеТабличногоДокументаДляРасширение.epf`** 
##### <span style="color:rgb(0, 176, 80)">2.</span> Подключить обработку к подсистеме **`ПодключаемыеОтчетыИОбработки`** 

##### <span style="color:rgb(0, 176, 80)">3.</span> Вырезать весь код из модуля для объекта обработки и перенести его в модуль менеджера обработки 

##### <span style="color:rgb(0, 176, 80)">4.</span> В модуле менеджера полученной обработки: 
- Исправить параметры в процедуре **`ПриОпределенииНастроек`**
- Исправить параметры в процедуре **`ДобавитьКомандыПечати`**
- Исправить параметры в процедуре **`Печать`**
- В функции **`СформироватьПечатнуюФорму`** воспользоваться "Конструктором запроса с обработкой результата" для формирования печатной формы (при составлении запроса не забудьте про необходимость выходного поля **`Ссылка`** и наложение условия "В" по этому полю)
- Использовать закомментированные фрагменты функции для подключения к стандарту
