**Подготовка** [[Методика подготовки форм объекта для работы с печатными формами]]

Чтобы создать и подключить новую внутреннюю печатную форму:
##### <span style="color:rgb(0, 176, 80)">1.</span> Надо собрать конструктором печатной формы новую печатную форму

##### <span style="color:rgb(0, 176, 80)">2. </span>Удалить добавившуюся команду печати документа

##### <span style="color:rgb(0, 176, 80)">3. </span>Добавить префикс ПФ_MXL к имени сформированного конструктором макета 
![[Pasted image 20250526123322.png]]
##### <span style="color:rgb(0, 176, 80)">4.</span> Добавить в процедуре **`ДобавитьКомандыПечати`** модуля менеджера документа фрагмент , посвященный программному созданию нашей команды на печать . Обязательными при этом являются указание Идентификатора и Представления команды 
![[Pasted image 20250526123804.png]]

##### <span style="color:rgb(0, 176, 80)">5.</span> Добавление в процедуре **`Печать`** модуля менеджера фрагмент, посвященный формированию табличного документа для нашей печатной формы и вызову процедуры **`ВывестиТабличныйДокументВКоллекцию`** с передачей ей этого табличного документа 
![[Pasted image 20250526124056.png]]

##### <span style="color:rgb(0, 176, 80)">6.</span> Процедуру, формирующую, наш табличный документ, **превратить в функцию** и точечно поправить в ней (по аналогии  подобными функциями)

- параметры в заголовке;
- объявление  табличного документа и установка уникального значения **`КлючПараметровПечати`** из табличного документа, пример:
```
	ТабДок = Новый ТабличныйДокумент();
	ТабДок.КлючПараметровПечати = "Оприход_печка";
```
- получение макета по имени с префиксом через функцию **`УпралвениеПечатью.ПолучитьМакет()`**;
- в выходной таблице запроса обязательно должно быть поле **`Ссылка`** (содержащее ссылку на печатаемый документ);
- определение номера строки начала табличного документа;
- задание областей печати;
- возврат табличного документа.
![[Pasted image 20250527080919.png]]

```
ТабДок = Новый ТабличныйДокумент();
	ТабДок.КлючПараметровПечати = "Накладная_печка";

	Макет = УправлениеПечатью.МакетПечатнойФормы("Документ._ДемоРеализацияТоваров.ПФ_MXL_Накладная");
```
