#бсп #отчеты_и_обработки 

> [[База знаний БСП]]

Чтобы подключаемая внешняя обработка автоматически загрузилась и распозналась системой, необходимо обеспечить, чтобы в модуле объекта обработки была экспортная функция **`СведенияОВнешнейОбработке`**.

При этом функция должна возвращать **структуру** следующего содержания:
- С ключом **`Вид`**: Строка, содержащая вид обработки, один из возможных: 
	1. **`ДополнительнаяОбработка`** 
	2. **`ЗаполнениеОбъекта`**
	3. **`Отчет`**
	4. **`ПечатанаяФорма`**
	5. **`СозданиеСвязанныхОбъектов`**
- С ключом **`Назначение`**: Массив строк имен объектов метаданных в формате: 
	- **`<ИмяКлассаОбъектаМетаданного>.[*|<ИмяОбъектаМетаданных>]`**
	Например, **`Документ.СчетЗаказ`** или **`Справочик.*`**
	Параметр имеет смысл только для назначаемых обработок, для глобальных — не используется.
- С ключом **`Наименвание`**: Наименование обработки, которым будет заполнено наименование элемента справочника, краткое описания для идентификации обработки администратором
- С ключом **`Версия`**: Версия обработки в формате <старший номер>.<младший номер> используется при загрузке обработок в информационную базу
	- 1.0, 2.0, 2.1 и т.д.
- С ключом **`БезопасныйРежим`**: Значение **`Истина`** или **`Ложь`** в зависимости от того, требуется устанавливать или отключать безопасный режим при исполнении обработки (отчета). Если **`Истина`**, обработка *(отчет)* будет запущена в безопасном режиме. При этом, в частности, не гарантируется корректная работа дополнительных обработок под пользователями без полных прав в тех случаях, когда обработка вызывает код конфигурации, который не рассчитан на работу в безопасном режиме *(в том числе неявно, когда срабатывает код модуля объекта и подписок на события при записи данных)*
- С ключом **`Информация`**: Краткая информация по обработке, описание обработки 
- С ключом **`ВерсияБСП`**: Минимальная версия БСП на которую рассчитывает код дополнительной обработки. Должна быть задана не ниже 2.4.1.4.  Номер версии БСП задается в формате **`РР.ПП.ВВ.СС`** (*РР - старший номер редакции; ПП - младший номер редакции; ВВ - номер версии; СС - номер сборки)*
- С ключом **`Разрешения`**: Массив разрешений, предоставляемых дополнительной обработке при использовании программного интерфейса, расширяющего доступные разработчику дополнительной обработки операции, при выполнении дополнительной обработки в безопасном режиме
- С ключом **`ОпределитьНастройкиФормы`**: Булево. Используется для дополнительных отчетов, подключенных к подсистеме "Варианты отчетов" и использующих общую форму отчета. Когда истина, то дополнительный отчет имеет программный интерфейс для тесной интеграции с формой отчета, в том числе может переопределять некоторые настройки формы и подписываться на её события
- С ключом **`Команды`**: Таблица значений  колонками:
	- **`Представление`** - строка, представление команды в пользовательском интерфейсе
	- **`Идентификатор`** - идентификатор команды; любая строка, уникальная в пределах данной обработки *(отчета)*
	- **`ПоказыватьОповещение`** - **`Истина`**, если требуется показать оповещение при начале и при завершении работы обработки . Например, при запуске обработки без открытия формы
	- **`Модификатор`** - дополнительный модификатор команды. Используется для дополнительных обработок печатных форм на основе табличных макетов. Для таких команд должен содержать строку ПечатьXML
	- **`ЗаменяемыеКоманды`** - используется для дополнительных обработок печатных форм, содержит идентификаторы стандартных команд печати (*строкой, через запятую)*, которые заменяются обработкой
	- **`Использование`** — один из следующих вариантов запуска команды:
		- **`ОткрытиеФормы`** -  открывает форму обработки
		- **`ВызовКлиентскогоМетода`** - вызывает клиентскую экспортную процедуру из модуля формы обработки
		- **`ВызовСерверногоМетода`** - вызывает серверную экспортную процедуру из модуля формы обработки
		- **`ЗаполнениеФормы`** - вызывает из модуля формы обслуживаемого объекта серверную процедуру модуля внешней обработки, используемую для заполнения формы исходного обслуживаемого объекта 
		- **`СценарийВБезопасномРежиме`** - вызывает серверную экспортную функцию из модуля объекта для интерфейса, расширяющего доступные разработчику дополнительной обработки операции, при выполнении дополнительной обработки в безопасном режиме
