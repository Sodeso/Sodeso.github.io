 [[Методика подготовки форм объекта для работы с печатными формами|Подготовка]]

Чтобы создать и подключить новую внутреннюю печатную форму:
 1. Надо собрать конструктором печатной формы новую печатную форму
 2. Удалить добавившуюся команду печати документа
 3. Добавить префикс ПФ_MXL к имени сформированного конструктором макета 
	 Например: **ПФ_MXL_НашаПечФорм**
4. Добавить в процедуре **`ДобавитьКомандыПечати`** модуля менеджера документа фрагмент , посвященный программному созданию нашей команды на печать . Обязательными при этом являются указание **Идентификатора** и **Представления** команды 	
	```bsl
		// Наша печатная форма
		КомандаПечати = КомандыПечати.Добавить();
		КомандаПечати.Идентификатор = "НашаПФ";
		КомандаПечати.Представление = НСтр("ru = 'Наша печатная форма'");
	```
5. Добавление в процедуре **`Печать`** модуля менеджера фрагмент, посвященный формированию табличного документа для нашей печатной формы и вызову процедуры **`ВывестиТабличныйДокументВКоллекцию`** с передачей ей этого табличного документа
	```bsl
		// Наша печатная форма
		ПечатнаяФорма = УправлениеПечатью.СведенияОПечатнойФорме(КоллекцияПечатныхФорм, "НашаПФ");
		Если ПечатнаяФорма <> Неопределено Тогда
			ПечатнаяФорма.ТабличныйДокумент = ПечатьНашейПФ(МассивОбъектов, объектыПечати, "НашаПФ");
			ПечатнаяФорма.ПолныйПутьКМакету = "Документ._НашДок.ПФ_MXL_НашаПечФорм";
		КонецЕсли;
	```
6. Процедуру, формирующую, наш табличный документ, **превратить в функцию** и точечно поправить в ней (по аналогии подобными функциями)
	- параметры в заголовке;
	- объявление  табличного документа и установка уникального значения **`КлючПараметровПечати`** из табличного документа;
	- получение макета по имени с префиксом через функцию **`УпралвениеПечатью.ПолучитьМакет()`**;
	- в выходной таблице запроса обязательно должно быть поле **`Ссылка`** (содержащее ссылку на печатаемый документ);
	- определение номера строки начала табличного документа;
	- задание областей печати;
	- возврат табличного документа.

```bsl
Функция ПечатьНашейПФ(МассивОбъектов, ОбъектыПечати, ИмяМакета = "НашаПФ")
	// Создаем табличный документ и устанавливаем имя параметров печати.
	ТабличныйДокумент = Новый ТабличныйДокумент;
	ТабличныйДокумент.ИмяПараметровПечати = "ПараметрыПечати_НашейПФ";
	Макет = УправлениеПечатью.МакетПечатнойФормы("Документ._НашДок.ПФ_MXL_НашаПечФорм");
	
	// Получаем запросом необходимые данные.
	Запрос = Новый Запрос();
	Запрос.Текст = 
	"ВЫБРАТЬ
	|"
```
