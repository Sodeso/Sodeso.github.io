> [[Библиотека стандартных подсистем (БСП)]]
---

Чтобы документ или справочник мог работать с печатными формами — его формы нуждаются в доработках определенного рода.

Поскольку в современных редакциях стандартной подсистемы печати используется программная сборка подмен печати, то важно что бы:
### 1. Была подготовлена форма объекта:  
#### 1.1
В обработчике **`ПриСозданииНаСервере`** должен вызываться стандартный алгоритм формирования подменю формы
```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	// СтандартныеПодсистемы.ПодключаемыеКоманды
		ПодключаемыеКоманды.ПриСозданииНаСервере(ЭтотОбъект);
	// Конец СтандартныеПодсистемы.ПодключаемыеКоманды
КонецПроцедуры
```

#### 1.2
Должен присутствовать блок процедур, обслуживающих создаваемые команды (именно с таким текстом)
```bsl
// СтандартныеПодсистемы.ПодключаемыеКоманды
&НаКлиенте
Процедура Подключаемый_ВыполнитьКоманду(Команда)
	ПодключаемыеКомандыКлиент.НачатьВыполнениеКоманды(ЭтотОбъект, Команда, Объект);
КонецПроцедуры

&НаКлиенте
Процедура Подключаемый_ПродолжитьВыполнениеКомандыНаСервере(ПараметрыВыполнения, ДополнительныеПараметры) Экспорт
	ВыполнитьКомандуНаСервере(ПараметрыВыполнения);
КонецПроцедуры

&НаСервере
Процедура ВыполнитьКомандуНаСервере(ПараметрыВыполнения)
	ПодключаемыеКоманды.ВыполнитьКоманду(ЭтотОбъект, ПараметрыВыполнения, Объект);
КонецПроцедуры

&НаКлиенте
Процедура Подключаемый_ОбновитьКоманды()
	ПодключаемыеКомандыКлиентСервер.ОбновитьКоманды(ЭтотОбъект, Объект);
КонецПроцедуры
// Конец СтандартныеПодсистемы.ПодключаемыеКоманды
```

#### 1.3 
В обработчике **`ПриЧтенииНаСервере`** должен вызываться стандартный алгоритм обновления подменю формы
```bsl
&НаСервере
Процедура ПриЧтенииНаСервере(ТекущийОбъект)
	// СтандартныеПодсистемы.ПодключаемыеКоманды
		ПодключаемыеКомандыКлиентСервер.ОбновитьКоманды(ЭтотОбъект, Объект)
	// Конец СтандартныеПодсистемы.ПодключаемыеКоманды
КонецПроцедуры
```

#### 1.4 
В обработчике **`ПриОткрытии`** должен вызываться стандартный алгоритм обновления подменю формы
```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	// СтандартныеПодсистемы.ПодключаемыеКоманды
		ПодключаемыеКомандыКлиент.НачатьОбновлениеКоманд(ЭтотОбъект)
	// Конец СтандартныеПодсистемы.ПодключаемыеКоманды
КонецПроцедуры
```

#### 1.5
Желательно создать реквизит формы **`ПараметрыПодключаемыхКоманд`** с типом — **`Произвольный`** (наличие такого готового реквизита несколько ускоряет открытие формы)

### 2. Была подготовлена форма списка: 

#### 2.1
В обработчике **`ПриСозданииНаСервере`** должен вызываться стандартный алгоритм формирования подменю формы
```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	// СтандартныеПодсистемы.ПодключаемыеКоманды
		ПодключаемыеКоманды.ПриСозданииНаСервере(ЭтотОбъект);
	// Конец СтандартныеПодсистемы.ПодключаемыеКоманды
КонецПроцедуры
```

#### 2.2
Должен присутствовать блок процедур, обслуживающих создаваемые команды (именно с таким текстом)
```bsl

&НаКлиенте
Процедура Подключаемый_ВыполнитьКоманду(Команда)
	ПодключаемыеКомандыКлиент.НачатьВыполнениеКоманды(ЭтотОбъект, Команда, Элементы.Список);
КонецПроцедуры

&НаКлиенте
Процедура Подключаемый_ПродолжитьВыполнениеКомандыНаСервере(ПараметрыВыполнения, ДополнительныеПараметры) Экспорт
	ВыполнитьКомандуНаСервере(ПараметрыВыполнения);
КонецПроцедуры

&НаСервере
Процедура ВыполнитьКомандуНаСервере(ПараметрыВыполнения)
	ПодключаемыеКоманды.ВыполнитьКоманду(ЭтотОбъект, ПараметрыВыполнения, Элементы.Список);
КонецПроцедуры

&НаКлиенте
``` 

### 3. В модуле менеджера объекта:

#### 3.1 
Должна быть заготовка под процедуру **`ДобавитьКомандыПечати`**
```bsl
Процедура ДобавитьКомандыПечати(КомандыПечати) Экспорт

КонецПроцедуры
``` 

#### 3.2 Должна быть заготовка под процедуру **`Печать`**
```bsl
Процедура Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВызова) Экспорт

КонецПроцедуры
``` 
### 4. В общем модуле **`УправлениеПечатьюПереопределяемый`**
#### 4.1
В процедуре **`ПриОпределенииОбъектовСКомандамиПечати`** **обязательно** следует проверить принадлежность вашего объекта метаданных к обслуживающему списку объектов. При необходимости - добавить:
```bsl
Процедура ПриОпределенииОбъектовСКомандамиПечати(СписокОбъектов) Экспорт
	//...
	СписокОбъектов.Добавить(Справочники._ДемоФизическиеЛица);
	
	СписокОбъектов.Добавить(Документы._ДемоСчетНаОплатуПокупателю);
	//
КонецПроцедуры
``` 

#### 4.2
Пример процедур ДобавитьКомандыПечати и Печать
```bsl
// Определяет список команд печати.
//
// Параметры:
//  КомандыПечати - см. УправлениеПечатью.СоздатьКоллекциюКомандПечати
//
Процедура ДобавитьКомандыПечати(КомандыПечати) Экспорт
	КомандаДоМеня = КомандыПечати.Добавить();
	КомандаДоМеня.Идентификатор = "_ДемоПроверитьРазрешениеНаПечать";
	КомандаДоМеня.Представление = НСтр("ru = 'Демо: Проверить разрешение на печать'");
	КомандаДоМеня.Обработчик    = "_ДемоСтандартныеПодсистемыКлиент.ПроверитьРазрешениеНаПечать";
	
	Команда = КомандыПечати.Добавить();
	Команда.Идентификатор = "Оприход";
	Команда.Представление = НСтр("ru = 'Оприход'");
	
	Команда = КомандыПечати.Добавить();
	Команда.Идентификатор = "Оприход,Основание_Поступление";
	Команда.Представление = НСтр("ru = 'Комплект оприхода и его основания'");
КонецПроцедуры

// Формирует печатные формы.
//
// Параметры:
//  МассивОбъектов  - Массив    - ссылки на объекты, которые нужно распечатать;
//  ПараметрыПечати - Структура - дополнительные настройки печати;
//  КоллекцияПечатныхФорм - ТаблицаЗначений - сформированные табличные документы (выходной параметр).
//  ОбъектыПечати         - СписокЗначений  - значение - ссылка на объект;
//                                            представление - имя области в которой был выведен объект (выходной
//                                                            параметр);
//  ПараметрыВывода       - Структура       - дополнительные параметры сформированных табличных документов (выходной
//                                            параметр).
//
Процедура Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода) Экспорт
	
	ПечатнаяФорма = УправлениеПечатью.СведенияОПечатнойФорме(КоллекцияПечатныхФорм, "Оприход");
	Если ПечатнаяФорма <> Неопределено Тогда
		ПечатнаяФорма.ТабличныйДокумент = Оприход(МассивОбъектов, ОбъектыПечати, "Оприход");
		ПечатнаяФОрма.СинонимМакета = НСтр("ru = 'Оприход'");
		ПечатнаяФорма.ПолныйПутьКМакету = "Документ._ДемоОприходованиеТоваров.ПФ_MXL_Оприход";
	КонецЕсли;
	
	ПечатнаяФорма = УправлениеПечатью.СведенияОПечатнойФорме(КоллекцияПечатныхФорм, "Основание_Поступление");
	Если ПечатнаяФорма <> Неопределено Тогда
		ПечатнаяФорма.ТабличныйДокумент = Документы._ДемоПоступлениеТоваров(МассивОбъектов, ОбъектыПечати, "Основание_Поступление");
		ПечатнаяФОрма.СинонимМакета = НСтр("ru = 'Поступление/Основание'");
		ПечатнаяФорма.ПолныйПутьКМакету = "Документ._ДемоОприходованиеТоваров.ПФ_MXL_Оприход";
	КонецЕсли;

	
КонецПроцедуры
```
