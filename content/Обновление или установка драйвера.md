Заходим в тест драйвер ккт -> устанавливаем галочку на "включить" -> проверяем в правом нижнем углу нынешнюю версию драйвера

<div id="toCopy">https://fs.atol.ru/</div> <button onclick="Copy('toCopy')" title="Copy">Copy</button>

На данном сайте выбираем нужную ккт и скачиваем архив -> разархивируем скачанный файл и в папке **installer** открываем **exe** и выбираем под разрядность компьютера

При установке не забыть поставить галочку работы с 1С

После окончания установки в тест драйвере можно проверить нынешнюю версию драйвера

<script type="text/javascript" >
function Copy(containerid) {
	    let textarea = document.createElement('textarea');
	    textarea.id = 'temp';
	    textarea.style.height = 0;
	    document.body.appendChild(textarea);
	    textarea.value = document.getElementById(containerid).innerText;
	    let selector = document.querySelector('#temp');
	    selector.select();
	    document.execCommand('copy');
	    document.body.removeChild(textarea);
}
</script>
